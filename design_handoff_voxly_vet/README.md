# Handoff: VOXLY Vet — דשבורד CRM למרפאת Get A Vet

> **שפה:** ה‑UI כולו בעברית, **RTL מלא** (`dir="rtl"`). כל הטקסטים, האייקונים הכיווניים והפריסות הפוכים.
> מסמך זה כתוב בעברית+אנגלית כדי שיהיה נוח לעבוד מולו ב‑Claude Code.

---

## Overview
דשבורד ניהול (CRM) למרפאה וטרינרית. המרפאה מפעילה **סוכן קולי AI בשם "תומר"** שעונה לשיחות נכנסות, קובע תורים, ומסלים מקרים דחופים לוטרינרית (ד״ר נועה כבשני). הדשבורד הוא מרכז השליטה: לוח יומי, יומן שבועי, יומן שיחות של תומר, אסקלציות רפואיות, וכרטיסי לקוח/חיה.

המרפאה: **Get A Vet** — מודל "וטרינר עד הבית" + מרפאה קטנה במגדלי גינדי TLV, תל אביב. **כלבים וחתולים בלבד.**

## About the Design Files
הקבצים בחבילה הזו (`reference_prototype/`) הם **רפרנס עיצובי שנבנה ב‑HTML/React (Babel in‑browser)** — פרוטוטייפ שמדגים מראֶה והתנהגות מכוונים, **לא קוד פרודקשן להעתקה ישירה**. המשימה היא **לשחזר את העיצובים הללו בסביבת הקוד של היעד** (React/Next, Vue, וכו') לפי הדפוסים והספריות הקיימות שם. אם אין עדיין סביבה — בחרו framework מתאים (מומלץ React + TypeScript) ויישמו שם.

הפרוטוטייפ משתמש ב‑React 18 דרך Babel standalone ובאובייקטי style inline. בפרודקשן עדיף: CSS Modules / Tailwind / styled‑components לפי הקיים, וקומפוננטות עם props מוגדרים. הערכים המדויקים (צבעים, מידות, טיפוגרפיה) נמצאים למטה ובקובץ `index.html` (בלוק `:root`).

## Fidelity
**High‑fidelity (hifi).** צבעים, טיפוגרפיה, מרווחים, מצבי hover/active ואנימציות סופיים. יש לשחזר pixel‑perfect תוך שימוש בספריות העיצוב של ה‑codebase. כל ה‑hex, ה‑radius וה‑shadow מתועדים.
