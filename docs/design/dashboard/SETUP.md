# SETUP — חיבור החבילה לקלוד קוד

חבילה זו מתעדת את עיצוב הדשבורד **VOXLY Vet** (דשבורד CRM למרפאת Get A Vet) כדי שתוכל לממש אותו בפרויקט קוד אמיתי בעזרת Claude Code.

> חשוב: Claude Code רץ בטרמינל **על המחשב שלך**. אי אפשר "לשלוח" אליו קבצים מרחוק — מעבירים את החבילה לתיקיית הפרויקט, ומשם Claude Code קורא ומיישם.

## שלבים

1. **חלץ** את התיקייה `design_handoff_voxly_vet` ושים אותה בתוך תיקיית הפרויקט שלך (למשל בשורש ה-repo).
2. פתח טרמינל בתיקיית הפרויקט והרץ:
   ```
   claude
   ```
   (אם Claude Code לא מותקן: התקן מ-`claude.com/code`.)
3. הדבק את הפרומפט הבא:

---

> קרא את `design_handoff_voxly_vet/README.md` ואת `design_handoff_voxly_vet/README_SCREENS.md`, ועיין בפרוטוטייפ הרפרנס תחת `design_handoff_voxly_vet/reference_prototype/` (אפשר לפתוח את `index.html` בדפדפן כדי לראות אותו חי).
>
> ממש את הדשבורד הזה בקודבייס שלי לפי הדפוסים, הספריות ומערכת העיצוב הקיימים בפרויקט. דרישות מחייבות:
> - **RTL מלא** (`dir="rtl"`): סרגל ניווט בצד **ימין**, טקסט מיושר לימין, חצים כיווניים הפוכים, וכל ה-Drawers נפתחים מצד **ימין**.
> - עברית בכל ה-UI, פונט Heebo, שעון 24 שעות, תאריכים בפורמט ישראלי.
> - השתמש ב-design tokens המתועדים ב-README (צבעי מותג כתום/קורל, טיפוגרפיה, רדיוסים, צללים, אנימציות) וכבד `prefers-reduced-motion`.
> - 5 המסכים: היום, יומן (תצוגת שבוע עם גרירה לשינוי מועד), שיחות (טבלה + drawer), אסקלציות, כרטיס לקוח — בנוסף ל-drawer סיכום ביקור.
>
> התחל במיפוי הקבצים הקיימים בפרויקט, הצע תוכנית מימוש קצרה, ואז יישם מסך-מסך.

## עריכות עתידיות
מרגע שהקוד בפרויקט שלך — Claude Code יכול לערוך אותו חופשי. פשוט בקש בשפה טבעית, למשל:
- "שנה את הכתום הראשי לגוון כהה יותר"
- "הוסף עמודת 'וטרינר מטפל' לטבלת השיחות"
- "הפוך את כרטיס האסקלציה לקומפקטי יותר"
